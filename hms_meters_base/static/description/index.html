Utility Meters/Counters

Odoo 14 Utility Meters/Counters base module

Features

  • Configurable meter types (Electricity, Gas, Water, Heat, etc.)
  • Easy to add/edit meter data
  • Data needed flag
  • Optional photo for meter data
  • User permissions to add/edit/delete meter types and meters/counters
  • Graph view for meter data

Meters/Counters list

  • Meters list with ready-to-use filter by "Data needed" flag
  • Group meters by
    • Meter/Counter type
    • Latest data date
  • Search by meter name and/or code
  • Meters kanban view with possibility to change the order of meters by drag-n-drop

Meter/Counter data

  • Meters data form with possibility to add meter photo with current value
  • Meters data list view with meter name, type, data datetime and value
  • Meters data graph view with possibility to group by data date and see stats

Separate user permissions

  • All internal users can read meters and data.
  • Separate user permission (please enable them for at least one user after module installation)
    • Create/Edit/Delete meter
    • Create/Edit/Delete meter data information
    • Create/Edit/Delete meter type
